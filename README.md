A catalogue photograph of an impossible gadget: **WiToast**, a stainless-steel
toaster that toasts the Wi-Fi password onto bread. One slice pops out of the
slot, golden-brown, with a Wi-Fi symbol and the password `hunter2` toasted
into its face. The product is the hero on a clean warm studio backdrop; the
toast is the single accessory that sharpens the joke.

`main.py` (Python 3.13, Pillow, no network) draws the photograph to
`/output/entry.png` — 1024 by 1024 pixels, deterministic: the same bytes on
every run.
